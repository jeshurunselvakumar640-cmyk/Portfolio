## 🛠️ Tech Stack

* **Framework**: Next.js 15 (App Router), React 18, TypeScript
* **Styling**: Tailwind CSS, Glassmorphism, Dynamic Canvas Spotlight
* **Physics & Audio**: Matter.js 2D Physics Engine, Web Audio API Polyphonic Synthesizer
* **AI Subsystem**: Google Gemini API (`@google/generative-ai`)
* **Icons & Animation**: Lucide React, Lenis Smooth Scrolling

## 📦 Getting Started

### 1. Clone Repository & Install Dependencies
```bash
git clone https://github.com/jeshurunselvakumar640-cmyk/Portfolio.git
cd Portfolio
npm install
```

### 2. Environment Setup
Create a `.env.local` file in the root directory:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build
```bash
npm run build
npm start
```
